# Ubatuba Célio Locações

Site estático (HTML, CSS e JS puros) com a vitrine de acomodações para temporada em Ubatuba/SP.
Cada acomodação tem um botão de reserva por WhatsApp.

## Onde editar
- `js/data.js`: acomodações (nome, capacidade, fotos), telefones e depoimentos.
- `img/<acomodação>/01.jpg…`: fotos de cada acomodação (a `01` é a capa do card).
- `index.html`, `css/style.css`, `js/app.js`: página, estilo e comportamento.

## Publicação
Sem build. Na Vercel: framework "Other", sem comando de build e sem pasta de saída.
